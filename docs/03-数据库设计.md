# 数据库设计文档

## 数据库表结构

### 用户表 (user)
| 字段名 | 类型 | 说明 |
|--------|------|------|
| id | BIGINT | 主键，自增 |
| username | VARCHAR(50) | 用户名，唯一（学号/工号） |
| password | VARCHAR(100) | 密码（加密存储） |
| name | VARCHAR(50) | 真实姓名 |
| role | ENUM('student','teacher') | 角色 |
| class_name | VARCHAR(100) | 班级名称（学生） |
| created_time | DATETIME | 创建时间 |
| updated_time | DATETIME | 更新时间 |

### 作业表 (homework)
| 字段名 | 类型 | 说明 |
|--------|------|------|
| id | BIGINT | 主键，自增 |
| teacher_id | BIGINT | 教师ID，外键关联user.id |
| title | VARCHAR(200) | 作业标题 |
| content | TEXT | 作业内容 |
| deadline | DATETIME | 截止时间 |
| attachment_path | VARCHAR(500) | 附件路径（可选） |
| status | ENUM('active','expired') | 作业状态 |
| created_time | DATETIME | 创建时间 |
| updated_time | DATETIME | 更新时间 |

### 作业提交表 (submission)
| 字段名 | 类型 | 说明 |
|--------|------|------|
| id | BIGINT | 主键，自增 |
| homework_id | BIGINT | 作业ID，外键关联homework.id |
| student_id | BIGINT | 学生ID，外键关联user.id |
| content | TEXT | 提交内容（可选） |
| attachment_path | VARCHAR(500) | 附件路径（可选） |
| status | ENUM('draft','submitted') | 提交状态 |
| submitted_time | DATETIME | 提交时间 |
| created_time | DATETIME | 创建时间 |
| updated_time | DATETIME | 更新时间 |

### 文件表 (file)
| 字段名 | 类型 | 说明 |
|--------|------|------|
| file_id | VARCHAR(50) | 文件ID（主键） |
| file_name | VARCHAR(255) | 原始文件名 |
| file_path | VARCHAR(500) | 存储路径 |
| file_size | BIGINT | 文件大小（字节） |
| uploader_id | BIGINT | 上传者ID，外键关联user.id |
| upload_time | DATETIME | 上传时间 |
| mime_type | VARCHAR(100) | 文件类型 |
